# Glow & Go — Feature Implementation

## 1. Read Project Context
- Read AGENTS.md and PROGRESS.md.
- Inspect relevant existing source files.
- Identify the current approved milestone.
- Do not assume missing files or features exist.

## 2. Plan Before Coding
Before making changes, provide:
- Feature objective
- Files to create or modify
- Implementation approach
- Acceptance criteria
- Verification commands

Wait for user approval before implementation.

## 3. Implementation Standards
- Follow the approved project tech stack.
- Keep React and Express separated.
- Prefer small, reusable components and functions.
- Use clear, consistent naming.
- Avoid unnecessary abstractions or dependencies.
- Do not introduce unrelated features.
- Never expose secrets or API keys.
- Validate inputs and handle errors appropriately.

## 4. Verification
After implementation:
- Run relevant available checks.
- Verify the acceptance criteria.
- Report actual results.
- Clearly identify anything not tested.
- Do not claim success without evidence.

## 5. Completion
- Summarize changed files.
- Explain how to test the feature.
- Update PROGRESS.md with verified progress.
- Suggest a meaningful Git commit message.
- Do not commit, push, or deploy without approval.
- Do not automatically start another milestone.
